Cara Pakai LokaLink

LokaLink menghubungkan Anda langsung dengan warga lokal Lombok — mulai dari pengalaman budaya, destinasi wisata, kuliner khas, hingga UMKM dan kerajinan tangan.

🎒 Untuk Traveler

1
Jelajahi Pengalaman

Buka tab Discover lalu pilih kategori: Local Experience, Destination, Kuliner, atau Usaha Lokal.

2
Lihat Detail & Booking

Klik kartu untuk melihat cerita host, lokasi Maps, daftar menu/produk, lalu tekan Booking Host untuk memesan.

3
Sewa Guide Lokal (Opsional)

Di halaman Destinasi, Kuliner, atau Usaha — tekan Sewa Guide Lokal, pilih guide, isi detail, lalu kirim permintaan.

4
Cek Dampak Anda

Buka tab Impact untuk melihat total kontribusi rupiah Anda ke ekonomi lokal dan rincian per kategori.

🏡 Untuk Local Host

1
Login sebagai Host

Pilih role Local Host saat login untuk mengakses Dashboard Host.

2
Kelola Booking Masuk

Di Bookings, lihat pesanan traveler → konfirmasi atau tolak. Termasuk pesanan guide lokal.

3
Tambah Pengalaman Baru

Buat listing pengalaman baru di Experiences untuk ditampilkan ke traveler.

⚡ Untuk Youth Connector

1
Daftarkan Host Baru

Bantu warga lokal (tetua, pengrajin, nelayan) yang belum melek digital mendaftarkan pengalaman mereka.

2
Kelola Akun Host

Masuk ke mode pendamping untuk mengelola listing dan booking atas nama host binaan.

3
Lihat Bagi Hasil

Pantau komisi 15% Anda di Earnings dari setiap booking host binaan yang berhasil.

💡 Tips Penting

  • Semua pembayaran dilakukan langsung ke warga lokal — tidak ada perantara.
  • Gunakan fitur Saved (♡) untuk menyimpan pengalaman favorit.
  • Hubungi host melalui tombol Hubungi Host di halaman booking.
  • Ganti bahasa aplikasi di Profil → Language.
